01 選方案

  • 標準方案：月費較低（50K 約 $49/月），通關後付 $149 啟動費。適合考試多次的人。
  • 免啟動費方案：月費較高（50K 約 $109/月），通關後 $0。適合有把握一兩次過的人。

02 考試（Trading Combine）

  • 最大虧損（EOD）：每日收盤結算，虧損線隨最高餘額上移，達初始資金後固定。例：50K Max Loss $2,000，起始線 $48,000 → 賺到 $52,000 時線移到 $50,000 固定。
  • 一致性 50%：單日最高獲利 ≤ 總獲利 50%，超過則獲利目標會被調高。最快 2 天可通關（只要沒有單日超過 50%）。虧損日不會重置你的最佳日；最佳日每天 3:10 PM CT 鎖定。官方有小幅緩衝，不必算到分毫。
  • 重置：每月續費得 1 個「重置代幣」，可累積不過期，爆倉手動消耗。
🆕 日風控（DLL）是「選配」不是必有官方：Combine 與 EX 帳戶的 DLL 可在結帳時自行選擇加購（加了就固定不能改）；Live 帳戶則強制自動有。參數：50K $1,000／100K $2,000／150K $3,000。觸發 DLL 不算違規——只是當日強制休息（平倉、取消掛單，隔天 5PM CT 恢復），帳號仍保有資格。
💡 加了 DLL 的好處：出金上限加倍。
⚠️ 出金前必看：第一次出金後，虧損線永久鎖死在初始餘額 一旦你申請第一次出金，虧損線就永遠鎖在起始資金水位、不再往上移。
白話：出金後你的緩衝＝留在帳戶裡沒領走的利潤。如果把利潤全部領光，帳戶只要小小波動就會爆倉。
對策：每次出金刻意留一些利潤當緩衝，別領到見底。

06 取消訂閱與退費（月費制最容易踩的坑）

Topstep 是這幾家裡少數走月費訂閱制的，所以「忘了取消被續扣」是中文社群最常見的抱怨。這一段把流程和時限講清楚。

怎麼取消

路徑：Dashboard → Billing（帳單頁）→ 訂閱右邊的「✕」→ 確認就這樣，不需要寫信。⚠️ 取消是不可逆的，而且沒有「重新訂閱」按鈕——想再考只能重新購買一個新的 Combine。所以在按下去之前先確定你真的不打算繼續。

取消之後帳號還能用嗎

取消只是停止下一次扣款，你已經付掉的那個月可以用到週期結束，不是按下去就馬上斷。也就是說如果你這個月還想再拚一下，可以先取消、繼續打到期末，不會有損失。這是最推薦的做法：買完就先去取消，把它當成單月購買，想續再手動買。

💡 申請退費要準備的資料交易金額、扣款日期、付款卡片後四碼，以及一段簡短說明。客服確認後才算正式受理——寄出信不等於已經在處理，沒收到回覆要主動追。

降低被續扣風險的做法

  • 買完立刻取消。當月照樣能打完，等於把訂閱制變成單次購買。這是最乾淨的作法。
  • 在手機日曆設一個到期前兩天的提醒。Topstep 不一定會提前通知你。
  • 看清楚你買的是哪個方案。標準方案月費低（50K 約 $49/月）但通關要付 $149 啟動費；免啟動費方案月費高（50K 約 $109/月）通關 $0。如果你預期要考三個月以上，標準方案總成本反而比較低；有把握一兩次過就選免啟動費。
  • 用低額度信用卡或虛擬卡付款，額度限縮，出問題也好停。

07 TopstepX 是什麼？（強制使用的自家平台）

Topstep 已經不讓你用 Tradovate 或 Rithmic 了，一律走自家的 TopstepX。這是它跟 Lucid、TradeDay 這些讓你自選平台的公司最大的體驗差異，買之前一定要知道。

它的來歷

TopstepX 是建在 ProjectX 技術之上的自家介面。2026/02/28 之後 ProjectX 變成 Topstep 專屬，同年 4 月 Topstep 併購 The Futures Desk 並把 TFD-X 整併進來，等於整條技術線收攏成一個平台。所以你現在搜到的 ProjectX 相關資訊，實務上談的就是 TopstepX。

能做什麼

  • TradingView 等級的圖表——透過官方合作整合，不是陽春自製圖表，這點比很多同業好。
  • DOM 階梯下單、拖拉改單、括號單與 OCO。
  • 未過濾的 CME 行情，低延遲。
  • 網頁版 + 手機版都能用，不必裝桌面軟體。
  • 想接自動化：有 REST / WebSocket API 與官方 SDK，需要申請 API key。
⚠️ 平台層直接執行風控日虧損、尾隨回撤、一致性這些規則是寫進平台裡即時強制執行的，碰到就立刻鎖，沒有事後申訴的空間。好處是你不會不小心違規而不自知，壞處是完全沒有緩衝——習慣 Tradovate 那種寬鬆環境的人要適應。

費用

平台本身包含在訂閱裡。但如果你要把 TopstepX 接到第三方工具（ProjectX Linking），是另外的月費，約 $14.50/月，官方常有折扣碼。純手動下單的人不需要這筆。另外 Live 帳戶存續期間 Topstep 全額支付 CME 數據費，這是它少數比同業大方的地方。

08 常見問題

Topstep 可以用 Tradovate 或 NinjaTrader 嗎？

不行。現在一律強制使用 TopstepX。如果你的策略高度依賴 NinjaTrader 的特定指標或 Sierra Chart 的自訂工具，Topstep 可能不適合你，建議改看 Lucid 或 TradeDay 那種可以自選平台的。

Topstep 是詐騙嗎？

Topstep 是這個產業裡歷史最久的公司之一，規則公開在官方 Help Center、出金流程明確，不屬於來路不明的平台。真正該注意的是規則會調整——2026 年就把 50K 帳號的出金上限從 $6,000 砍到 $3,000、100K 砍到 $4,000。買之前務必以官網當下版本為準，不要照著別人半年前寫的教學做規劃。

台灣人可以開嗎？有哪些商品不能碰？

可以。但要注意 Topstep 限制部分商品：黃金（GC）、白銀（SI）、銅（HG）、鉑金（PL）、天然氣（NG、QG）都不能交易。習慣做貴金屬的人要先確認自己的主戰場有沒有被擋掉。

爆倉了怎麼辦？

考試階段用重置代幣：每月續費會給 1 個，可以累積而且不過期，爆倉時手動消耗。EX 帳戶爆倉且從未出金過的話，可以用 Back2Funded 付費復活，每個帳號最多 2 次。一個人最多同時持有 5 個 EX 帳戶。

為什麼領完錢帳號反而更容易爆？

這是 Topstep 最容易被忽略的一條：出金後虧損線會永久鎖在初始餘額。所以如果你把利潤全部領光，帳戶等於毫無緩衝，一點小波動就爆倉。正確做法是每次出金留一部分利潤在帳上當緩衝，不要領到見底。
